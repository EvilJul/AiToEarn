# 企业小红书工作台操作手册

## 启用与入口

部署需使用包含企业模块的前后端源码或镜像。后端配置 `enterpriseOps.enabled: true`，前端构建设置 `NEXT_PUBLIC_ENTERPRISE_OPS_ENABLED=true`，入口为 `/enterprise`。默认不改变原多平台工作区。

当前 Web 企业入口发起人工发布任务；服务端浏览器协议用于后续扩展适配，开关不会补齐浏览器驱动。企业审核门禁约束企业任务，不代替对原生平台或原个人工作区操作的管理。

浏览器执行协议的独立开关 `enterpriseOps.browserExecutionEnabled` 默认关闭。只有扩展已实现本项目的审核任务协议，且目标域名、账号身份、提交与中断恢复均完成验收后才能启用。原插件能连接、能填充内容或返回版本号，都不能单独证明它支持企业审核协议。普通私信、评论和小程序客服自动收发分别接入，不由此开关启用。

企业工作台当前提供中文、英文界面，其他界面语言使用英文回退。企业 AI 编排复用已配置的默认规划模型；也可以使用已审事实和授权图片人工编辑图文，答复建议为已审知识原文摘录。

## 管理员建档与成员

创建企业时填写行业、服务区域和 IANA 时区。区域、关键词及话题以逗号分隔；日期输入按浏览器本地时间解释，发布列表按企业时区显示。企业名称、行业、区域与时区可在设置中更新。

管理员通过已有注册用户 ID 添加成员，分配运营、审核员、销售或管理员角色。运营创建内容及发布任务，审核员批准或退回具体版本，销售接管并跟进咨询。作者自审默认禁止；管理员如需例外，须在企业设置中明确启用，变更会进入审计。

个人历史账号和素材不会自动共享。选定图片保存内容、或选定账号创建任务，是对本企业的明确授权。企业成员可使用已经授权的资源；管理员或原授权人在资源接口中可以撤回授权，管理员也可在设置页面操作。原个人资源不会随授权撤回而删除。

## 企业资料与选题

录入产品、价格、真实案例、FAQ 或品牌规范，并填写事实来源及有效期。资料需要审核后才能用于内容或答复。修改事实时创建新版本，不覆盖旧版；新版本批准后旧批准版本失效。撤回或到期的知识会阻断依赖它的未提交任务。证据附件支持已授权图片，附件内容摘要会被核对。

选题中心使用人工来源与常青选题，保存行业、地区、关键词和时效。默认仅展示未过期且匹配企业行业及区域的候选；可切换查看全部来源。它不是小红书实时热榜。采纳后可进入图文创作，内容会保留选题来源快照。

## 图文与审核

在企业编辑器直接上传有权使用的图片，或选择已有素材，并确认图片顺序、批准资料、标题、正文及话题，查看笔记预览后保存草稿。图片格式和篇幅按照当前小红书平台配置检查。每张图片遵守平台大小限制，一份发布素材包总量最多 50 MiB。

可先使用封面、真实案例和 FAQ 图片模板：选择有效已审资料，案例模式再选择真实授权照片，预览后生成并使用。模板采用当前主题；过长文本会要求人工精简，不静默截断事实条件。生成图片复用当前素材库上传与权限，仍需保存草稿并经过内容审核。

提交审核后，审核员核对事实、素材、来源和排版，再批准或填写退回原因。批准绑定具体内容与图片摘要；替换文件内容、图片顺序或文案需要创建并审核新版本。素材处理成功和笔记预览都不代表审核通过。

## 人工发布与结果核验

1. 选定已审版本、小红书账号及计划时间，创建人工发布任务。
2. 下载素材 ZIP，里面包含有序图片、标题、正文、话题和审核摘要。导出前服务端再次核对知识、权限和实际图片内容。
3. 在小红书创作者后台或官方客户端核对账号并完成发布。系统不会因为下载了素材包就标记成功。
4. 回填完整的 `https://www.xiaohongshu.com/explore/<作品ID>` 或 `/discovery/item/<作品ID>` 链接。短链和其他站点地址不作为作品链接接收。
5. 任务进入“已提交、待核验”；审核人员核对账号、内容和作品后填写依据，才转为“发布已核验”，并保留人工核验标记。

结果未知时先查找原作品，补充链接及核验结果，再决定后续操作。禁止因为断线或超时直接重复点击平台发布。主动再次发布已核验内容时建立新的业务任务，保留原任务关系与独立幂等标识。

浏览器任务依赖在线执行设备及有效登录。设备离线时保留等待状态；任务一旦进入提交中后失联，进入结果未知，不自动重新派发。设置页面提供设备心跳、版本、撤销和原插件连接状态。

## 人工咨询与销售跟进

在小红书原生工作台实际回复，将客户需求、来源及必要证据人工登记到企业工作台。后续客户消息也可人工补录，消息历史显示最近 100 条登记内容，不能当作平台实时会话同步。

明确的人工请求、询价、预约、购买和主动留资信号会产生带消息依据的线索及站内待办。知识答复建议仅展示有效已审资料的相关原文；缺少依据时转负责销售处理，不能编造报价、案例或服务承诺。

销售确认接管后，记录跟进、阶段及下次联系时间。站内提醒通过持久事件投递，失败保留并重试；管理员可配置无人接管提醒时限，默认 5 分钟，跟进到期会产生提醒。标记通知已读不代表销售接管。通知记录与销售接管是两个状态。未完成授权的渠道保持人工模式，不能恢复机器人接待，也不宣称普通私信自动化。

## 故障与回退

- 无插件：继续使用审核素材包、原生平台发布和人工核验。
- 资料撤回或过期：更新知识及内容依据，重新审核；不通过重试绕过校验。
- 版本冲突：刷新记录后重新核对，不能用旧表单覆盖其他人的修改。
- 账号或资源授权失效：由资源所有者重新授权，或选择其他已授权资源。
- 关闭企业模式：先停止新的执行任务及提交授权，保留正在提交任务的结果核验，再关闭企业入口；不删除知识、审核、咨询和历史发布记录。

企业资料、咨询、附件和导出均受成员权限约束。数据保存、导出和删除期限需由企业确定。模型、平台账号、通知服务和 Relay/MCP 凭据分开管理；中国版 Key 仅搭配 `aitoearn.cn`，国际版 Key 仅搭配 `aitoearn.ai`。

企业模式必须配置独立成员登录：`auth.secret` 至少 32 字符、使用随机值并与签发登录令牌的服务保持一致；内置占位值不能启用企业模式。企业构建不会把 `AUTO_LOGIN_TOKEN` 传入浏览器，后端拒绝 `admin@aitoearn.local` 共享身份及带 sharedBootstrap 标记的初始化令牌（含该保留用户的 API Key）。请先配置正常邮箱或 OAuth 登录。由旧单人部署迁移时，需撤销已分发的共享凭据、清理浏览器旧登录，并显式处理旧资料归属，不默认转移数据。

企业 AI 编排复用现有默认规划模型：选择已批准资料后生成，人工确认文案，再使用授权照片/品牌模板配图并保存审核。完整段落按来源校验，缺少依据不补造事实。生成任务和每次显式重试保存在用量记录，关闭编辑器不取消服务端任务；未确认调用不自动重试。已知 tokens 和供应商请求 ID 按返回记录，费用未知时不记零；管理员可依据供应商凭证调用 `POST /enterprise-ops/enterprises/:enterpriseId/usage/:id/reconcile` 提交 `cost/currency/reference` 对账，相同凭证与金额可幂等重放，冲突被拒绝。
